Шаг 1. На самом контроле uscSubscriptionOplataPrepod (файл uscSubscriptionOplataPrepod.cs, НЕ .Designer.cs)

Добавить enum и публичный метод. Внутри метода обращение к groupBox идёт напрямую — вложенность не важна.

public enum SoglasovanieMode
{
    DocumentPrepod, // форма документов: Инженер + Ответственный
    Vedomost        // форма ведомости: только Начальник
}

/// <summary>Показывает нужные блоки согласования в зависимости от формы.</summary>
public void SetSoglasovanieMode(SoglasovanieMode mode)
{
    switch (mode)
    {
        case SoglasovanieMode.DocumentPrepod:
            groupBox1.Visible = true;   // Инженер
            groupBox2.Visible = true;   // Ответственный
            groupBox3.Visible = false;  // Начальник
            break;

        case SoglasovanieMode.Vedomost:
            groupBox1.Visible = false;  // Инженер
            groupBox2.Visible = false;  // Ответственный
            groupBox3.Visible = true;   // Начальник
            break;
    }
}

Важно: метод кладётся в редактируемый файл кода контрола (uscSubscriptionOplataPrepod.cs), а не в .Designer.cs (тот перезаписывается конструктором).

Шаг 2. Найти имя экземпляра контрола на каждой форме

Когда контрол перетащен на форму, конструктор создал поле в <Форма>.Designer.cs, например:

private ARMS.View.ViewForms.uscSubscriptionOplataPrepod uscSubscriptionOplataPrepod1;

Имя (uscSubscriptionOplataPrepod1 или ваше) понадобится в шагах 3-4. Найти: открыть .Designer.cs формы и поискать тип контрола, либо кликнуть по контролу на форме и посмотреть (Name).

Шаг 3. Форма документов frmOplataPrepod (файл frmOplataPrepod.cs)

Вызвать метод в обработчике загрузки формы (через окно событий формы -> Load, двойной клик), либо в конструкторе после InitializeComponent().

private void frmOplataPrepod_Load(object sender, EventArgs e)
{
    uscSubscriptionOplataPrepod1.SetSoglasovanieMode(
        uscSubscriptionOplataPrepod.SoglasovanieMode.DocumentPrepod);
}

Шаг 4. Форма ведомости frmOplataVedomost (файл frmOplataVedomost.cs)

Аналогично, но другой режим:

private void frmOplataVedomost_Load(object sender, EventArgs e)
{
    uscSubscriptionOplataPrepod1.SetSoglasovanieMode(
        uscSubscriptionOplataPrepod.SoglasovanieMode.Vedomost);
}

Если контрол лежит на скрытой/неактивной вкладке TabControl — это не мешает: Visible у GroupBox выставится сразу, отрисуется при открытии вкладки.

Где что прописывать — сводка





uscSubscriptionOplataPrepod.cs — enum SoglasovanieMode + метод SetSoglasovanieMode(...) (шаг 1).



uscSubscriptionOplataPrepod.Designer.cs — НИЧЕГО не трогаем (там уже есть поля groupBox1/2/3).



frmOplataPrepod.cs — вызов SetSoglasovanieMode(DocumentPrepod) в Load (шаг 3).



frmOplataVedomost.cs — вызов SetSoglasovanieMode(Vedomost) в Load (шаг 4).

Альтернатива без метода (если не хотите enum)

Можно открыть каждый GroupBox в конструкторе контрола и в Свойствах выставить Modifiers = Public, тогда с формы доступно uscSubscriptionOplataPrepod1.groupBox3.Visible = false;. Но это хуже инкапсулирует логику; рекомендуется метод из шага 1.


Шаг 1. Открыть форму в конструкторе
Solution Explorer → двойной клик по форме (например frmVedomostOplata.cs) → откроется визуальный конструктор.

Шаг 2. Найти TabControl и добавить вкладку
Кликните по TabControl на форме (выделится синей рамкой).
В окне Свойства (F4) найдите свойство TabPages → нажмите кнопку «...».
В редакторе коллекции Add → появится новая TabPage.
Задайте ей:
(Name) = tabNew
Text = «Новая вкладка»
OK.
Где это в коде: VS сам допишет в frmVedomostOplata.Designer.cs строки this.tabNew = new TabPage();, this.tabControl1.Controls.Add(this.tabNew); и объявление поля private TabPage tabNew;.

Шаг 3. Положить контролы на вкладку
В конструкторе кликните по новой вкладке, чтобы она стала активной.
Из Toolbox (Панель элементов) перетащите:
DataGridView → задайте (Name) = dgvNew, Dock = Fill.
При желании сверху Panel/FlowLayoutPanel с кнопками (Dock = Top).
Порядок важен: контрол с Dock = Fill должен быть позади (добавлен раньше) контролов с Dock = Top/Bottom. В дизайнере это правится через ПКМ по контролу → «Bring to Front / Send to Back».

Шаг 4. Добавить BindingSource
В Toolbox найдите BindingSource (раздел «Данные»).
Перетащите его на форму — он появится в лотке компонентов внизу конструктора (не на самой форме).
Задайте (Name) = blNewBindingSource.
Шаг 5. Привязать грид к BindingSource
Выделите dgvNew → Свойства → DataSource → выберите blNewBindingSource.
Тип данных источнику задаётся в коде (см. шаг 7), после этого колонки можно сгенерировать кнопкой «Edit Columns» или оставить авто-генерацию.
Шаг 6. Подписаться на события (двойной клик / вкладка событий)
Кнопка: двойной клик по ней в конструкторе → VS создаст метод btnXxx_Click в .cs и подпишет его в .Designer.cs.
Загрузка данных при открытии вкладки: выделите TabControl → в Свойствах значок «молния» (события) → SelectedIndexChanged → двойной клик. В обработчике:
private void tabControl1_SelectedIndexChanged(object sender, EventArgs e)
{
    if (tabControl1.SelectedTab == tabNew)
        SetDataSourceNew();
}
Шаг 7. Написать метод наполнения (в .cs, легаси-стиль SetDataSource*)
private void SetDataSourceNew()
{
    List<BLNew> res = (from t in ListData.GetNew()
                       select new BLNew
                       {
                           Id = t.Id,
                           Название = t.Name
                       }).ToList();
    blNewBindingSource.DataSource = new BindingList<BLNew>(res);
}
Шаг 8. Класс-строка для грида (BL-класс)
public class BLNew
{
    public int Id { get; set; }
    public string Название { get; set; } = "";
}
Шаг 9. Форматирование колонок
Подпишитесь на dgvNew.DataBindingComplete (через окно событий) и скройте/переименуйте колонки:

private void dgvNew_DataBindingComplete(object sender, DataGridViewBindingCompleteEventArgs e)
{
    if (dgvNew.Columns["Id"] != null)
        dgvNew.Columns["Id"].Visible = false;
}
